スイング本数の感度

エントリーを Swing High/Low の抜け（前後N本で確定、一度抜かれたラインは次のスイング確定まで無効）にして、1時間足（6〜48本） / 2時間足（3〜24本） / 3時間足（2〜16本） / 4時間足（3〜18本）で N を動かした結果。フィルターは日足MA20/75/200の並び + ER(20)≥0.3。SL/TP は4時間足 ATR(14) × 1.0 / 1.5。15ペア、2021〜2025。

足の長さ（1時間足 / 2時間足 / 3時間足 / 4時間足）を変えても、時間幅ごとの成績は近い形になりました。 共通の時間幅の中では 24時間が最高（足の平均 +74R）です。

共通の時間幅（12時間, 24時間, 36時間, 48時間）で、同じ時間幅の足違いによるばらつきは合計Rで平均 5R、時間幅の違いによるばらつきは 23R です。1取引あたりでは 0.011R と 0.066R です。最良は 1時間足 24本（24時間・+82R・471回）、2時間足 12本（24時間・+74R・466回）、3時間足 8本（24時間・+78R・458回）、4時間足 6本（24時間・+62R・454回）。マイナスになったのは 1時間足6本（6時間・-107R）、2時間足3本（6時間・-110R）、3時間足2本（6時間・-94R） です。

読むときの注意

  • 誤差の目安: 1取引のRの標準偏差は約1.25R。合計Rの誤差は、取引454回で±27R、471回で±27R 程度です（時間幅 24時間）。隣り合う本数の取引は大部分が重なっているので、本数が違う結果は独立ではありません。
  • これまでに試した方式・本数は延べ23通り以上あります。最良の本数だけを選ぶと合わせ込みになります。
  • 足の長さが違っても、同じ時間幅のスイングは、ほぼ同じ価格の山谷から作られます。そのため、足ごとの結果が近いのは、独立した確認というより、足の長さが成績にほとんど影響しないことを示しています。実質的に動かしているパラメータは「時間幅」の1つです。
  • 「+傾き」は、さらに20MAの傾き（1日）を足した場合の合計R、「MAのみ」は ER を使わない場合の合計Rです。
  • スワップは未考慮です。データは2021〜2025年の5年間のみです。
