ほぼ全部を落としているのは「ハンドル中の ATR14 平均 < 0.8×ATR50」。これを外しても日足では5件。4時間足にすると20件約定して +2.7R だが、ランダムエントリーとの差は偶然の範囲（p≈0.24）。B と C はデータを見た後に緩めた参考値。

わかったこと

原因ATR収縮の条件がほぼ満たせない

他の条件を全部満たした形が日足で7件あったが、すべてハンドル中の ATR14 平均が 0.8×ATR50 以上で落ちた。ATR14 はワイルダー平滑で反応が遅く、5〜25本のハンドルの平均には右縁までの上昇の値動きが残る。合成データでも、カップの右側から値幅を縮めないと通らなかった。

日足収縮を外しても5件・全部トレーリング決済

B（日足・ATR収縮なし）はシグナル7件・約定5件・合計 −2.19R。どれも 2R に届く前にチャンデリア（高値 − 3×ATR14）を終値で割って決済した。件数が少なすぎて良し悪しは判断できない。

4時間足20件で +2.7R、コストや±20%では崩れない

C（4時間足・ATR収縮なし）は勝率50%・PF 1.32・最大DD 4.7R。スプレッド2倍でも +2.6R、主要パラメータ±20%の6通りはすべてプラス。ただし同じ回数のランダムエントリーでも24%の確率で平均Rがこれを上回り、パターンの優位性は示せていない。

見送り4時間足ではシグナルの半分を見送り

38件中18件を見送った。始値がピボットから 1×ATR14 超離れていた（追いかけ）が8件、損切り幅が 3×ATR14 を超えたのが8件。4時間足では深いハンドルの安値までの距離が ATR14 に比べて広くなりやすい。

売買ルール

トレンド

終値 > SMA200 かつ SMA200 が20本前より上（売りは反対）。

左縁とカップ

左右5本で最高値のスイングハイが左縁。その前60本の安値から 6×ATR50 以上の上昇。左縁から右縁まで30〜150本、深さ 3〜10×ATR50、底は期間の25〜75%の位置、底から 1.5×ATR50 以内の安値の足が20%以上、右縁は左縁高値 −1×ATR50 以上まで回復。

ハンドル

右縁の翌足から5〜25本。押しは 0.5〜2.5×ATR50 かつ深さの半分以下、カップの上半分。ハンドル中の ATR14 の平均 < 0.8×ATR50。

エントリー

終値が右縁高値 + 0.1×ATR14 を超えたら、次の足の始値で成行。ハンドル完成から10本でブレイクしなければ失効、終値がハンドル安値を割ったら破棄。始値がピボットから 1×ATR14 超離れていたら見送り。

決済

初期損切り = ハンドル安値 − 0.5×ATR14（幅が 1〜3×ATR14 でなければ見送り）。+2Rで半分を利確し、残りの損切りを建値へ。チャンデリア（エントリー後の高値 − 3×ATR14）を終値で割ったら次の始値で決済。40本で+1R未満なら次の始値で決済。

資金管理とコスト

口座 JPY、1回のリスクは資産の 0.5%（0.01ロット単位で切り捨て、レバレッジ10倍まで）。同時保有は最大3、同じ通貨を含むのは最大2。スプレッド（pips）: AUDUSD 0.9、EURUSD 0.5、GBPUSD 1.3、USDCHF 2.0、USDJPY 0.4。スリッページ 成行0.5 / 逆指値1.0pips。スワップは未設定（0）。

  • A 仕様どおり（日足）: 変更なし（config.yaml の初期値）
  • B 日足・ATR収縮なし: handle_atr_contraction=99
  • C 4時間足・ATR収縮なし: bar_hours=4, handle_atr_contraction=99

注意点

  • B と C は、A の結果（0件）と「条件を1つ外したとき」の表を見てから選んだ緩和で、仕様書の検証ではない。C の 4時間足では本数で決めた期間（SMA200・カップ30〜150本・タイムストップ40本など）の意味も日足と変わる（SMA200 ≒ 33日）。
  • ウォークフォワードと銘柄分割は、学習期間の件数が4〜18件しかなく、選ばれた設定（深さ×1.2 など）は偶然に左右される。検証期間を合わせても8件・+5.0R。
  • スワップは表が空のため全取引で 0。4時間足の保有は中央値で約20本（3〜4日）なので影響は小さいが、日足で長く持つ場合は結果が変わる。
  • データは 2020-01〜2025-12 の5ペアだけ（クロス円などは無い）。日足は SMA200 の助走に約10か月使うため、A と B の実質的な検証期間は 2020-11 以降。
  • 損切りと部分利確は足の高値・安値で判定し、同じ足で両方に届いたら損切りを優先した（仕様どおり、1分足の順番は見ていない）。
  • 仕様にない部分の決め方: 右縁は仕様4.3の文面どおり下限だけ、左縁から底までに左縁より高い足が無いこと、ハンドル完成 = 初めて全条件を満たした足、チャンデリアのラインは下げない、同じペアは1ポジションまで、エクスポージャーの数え方は通貨ごと。
