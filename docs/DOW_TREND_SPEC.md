# ダウ理論トレンド判定 仕様

高値・安値の切り上げ（切り下げ）をルール化したトレンド判定。参照実装は `dow_trend.py`、検証は `tests/test_dow_trend.py`。
最初は JavaScript のインタラクティブチャートで作り、感覚と照らし合わせて調整したルールを Python に移植している
（JS 版と Python 版は、15分/1時間/4時間足 × N=2,3,5 × ATR倍率 0,1,2 × ヒゲ/終値の 54 通りで判定が完全一致することを確認済み）。

## パラメータ（`DowConfig`）

| 名前 | 既定 | 意味 |
|---|---|---|
| `n` | 3 | ピボット幅。左右 n 本より高い(低い)足をスイングハイ(ロー)とする |
| `atr_period` | 14 | ATR 期間（ワイルダー平滑化） |
| `min_swing_atr` | 1.0 | 最小スイング幅（ATR の倍数）。0 でフィルターなし |
| `use_wick` | True | True: ヒゲ（高値/安値）で抜けたらブレイク。False: 終値で判定 |

## 1. ピボット（スイングハイ/ロー）

- バー j のスイングハイ: 左右 n 本の高値より**厳密に**高い（同値は不採用）。スイングローも同様。
- 確定はバー j+n（右側 n 本が揃った時点）。以降のバーでのみ使える。**判定は常に n 本遅れる。**
- 採用ルール（直前に採用したピボットとの関係）
  - 逆の種類（H の次に L など）: `|価格差| ≥ min_swing_atr × ATR(確定したバー)` なら採用、未満なら捨てる。
  - 同じ種類が続く: より極端な方（高い H / 低い L）に置き換える。幅の条件は見ない。
  - 結果として H と L は必ず交互に並ぶ。捨てたピボットは後から復活しない。

## 2. トレンド状態（1=上昇, 0=レンジ, -1=下降）

毎バー、確定済みの直近スイングハイ `SH` とスイングロー `SL` に対してブレイクを判定する。

- 下抜け: `Low < SL.price`（`use_wick=False` なら `Close < SL.price`）
- 上抜け: `High > SH.price`（同上）
- 両方抜けた足は、陽線なら上抜け、陰線なら下抜けとして扱う。

**下抜けのとき**（安値更新の足で即判定）
- `戻り高値` = SL のバーから直前のバーまでの最高値、`前のH` = SL の一つ前のピボット（スイングハイ）。
- `戻り高値 < 前のH.price` なら **下降**（高値・安値とも切り下げ）。
- そうでなければ、上昇中だった場合のみ **レンジ**に変える（それ以外は状態を維持）。

**上抜けのとき**（対称）
- `押し安値` = SH のバーから直前のバーまでの最安値、`前のL` = SH の一つ前のピボット（スイングロー）。
- `押し安値 > 前のL.price` なら **上昇**。
- そうでなければ、下降中だった場合のみ **レンジ**に変える。

ブレイクがない足は前の状態を維持する。初期状態は 0。

## 3. 検証済みの挙動（USDJPY 2026年1月・1時間足・BID・日本時間, N=3, ATR 1.0, ヒゲ）

| 時刻 | 判定 | 理由 |
|---|---|---|
| 1/14 16:00 | 上昇 | |
| 1/14 17:00 | 下降 | 直近ロー 159.082 を割り、戻り高値 159.349 < 前のハイ 159.454 |
| 1/15 21:00 | 下降 | 継続 |
| 1/15 22:00 | 上昇 | ハイ 158.733 を上抜け、押し安値 158.303 > 前のロー 158.100 |

N=5 では 1/14 12:00 の安値がスイングローにならず、1/14 17:00 は上昇のまま（Nが大きいほど遅れる）。

## 4. 設計上の注意

- 未来のデータは使わない（`test_no_lookahead` で、末尾を切ったデータと全期間の結果が一致することを検証）。
- ATR は判定足の時間足で計算する。同じ倍率でも時間足により幅が変わる。
- 既存の `main_4H.py` は NY 17:00 区切りの4時間足を使っている。組み込む場合は、`resample_to_signal_bars` の出力
  （Open/High/Low/Close 列）をそのまま `compute_dow_trend` に渡せる。
- 検証用チャートでの感覚との比較は、ブレイク即判定にしたことで調整済み。未検討の候補:
  判定が出てから最低数本は維持しないとトレンドとして扱わない、固定 pips の最小スイング幅。

## 5. 使い方

```python
from dow_trend import DowConfig, compute_dow_trend

trend, pivots = compute_dow_trend(df_1h, DowConfig(n=3, min_swing_atr=1.0, use_wick=True))
# trend: 各バーの 1 / 0 / -1、pivots: 採用されたスイング（確定バー付き）
```

テスト: `python tests/test_dow_trend.py`（pytest でも可）。テスト用データ `tests/data/USDJPY_2026-01_1h_bid_JST.csv` は
GMOクリック証券の1分足（BID）を1時間足に合成したもの（日本時間）。
