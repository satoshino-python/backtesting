# FX版ミネルヴィニ戦略（通貨順位方式）のルールと実装

検証コード: `minervini_fx.py`（エンジン）/ `main_minervini_fx.py`（実行・感度分析・チャート）/ `minervini_report.py`（レポート）/ `minervini_cache.py`（1分足キャッシュ）。
`python minervini_cache.py` → `python main_minervini_fx.py` → `python minervini_report.py minervini_results/<フォルダ>`。テストは `tests/test_minervini_fx.py`。

## ルール（ユーザー作成のルールの要約）
1. 通貨強弱: 7通貨（USD EUR JPY GBP AUD NZD CHF）。ペアの63日対数リターンを σ√63 で割り（z）、通貨ごとに他6通貨との平均（クォート側は符号反転）。上位3＝買う通貨、下位3＝売る通貨。
2. 候補: ロング＝ベースが上位3・クォートが下位3、ショート＝逆。順位はエントリー判断の日だけ使い、保有中の決済には使わない。
3. トレンドテンプレート（終値）: 150・200日線の上、150>200、200日線が上昇、50日線が150・200の上、終値>50日線、52週レンジ内位置≥70%（ショートは反転・≤30%）。
4. エントリー: VCP（調整幅がATR単位で毎回縮小）。最後の収縮の高値（ショートは安値）がピボット。タッチで逆指値約定。
5. 損切り: 約定価格からATR14×2（固定）。トレンド崩れ: 直近10日安値（ショートは高値）のタッチ。先に触れた方。一部利確・ピラミッディングなし。
6. サイズ: ペア別口座1万ドル、1回のリスク200ドル固定。

## ルールに書かれていないため決めた点（実装）
| 項目 | 決め方 |
|---|---|
| 日足の区切り | NY17:00（既存の検証と同じ）。ATR は Wilder 14 |
| 取引できるペア | データのある15ペア。AUDNZD・AUDCHF・NZDCHF・EURNZD・GBPNZD・CHFJPY は取引せず、通貨強弱の計算だけに USD 経由の合成レートで使う |
| 200日線の上昇 | 21営業日前より高い（感度分析で63・105日） |
| スイング | 前後3日のフラクタル（確定は3日後）。高値・安値が交互になるジグザグに整理 |
| VCP | 末尾2回の調整幅（ATR単位、安値側確定日のATR）が縮小。起点の高値から判定日まで60日以内、最初の収縮から120日以内。ピボットを既に超えていたら無効 |
| 注文の期限 | 判定日の終値で確定、翌取引日のみ有効（毎日判定し直す）。保有中は新規の判定をしない |
| 窓開け | ピボットを窓で越えたら始値で約定。損切り・10日安値/高値を窓で越えたら始値で手仕舞い |
| 同じ1分足で約定と損切り | 損切り優先 |
| 10日安値/高値 | 前日までの10日。損切りと10日安値の高い方（ショートは低い方）を逆指値として毎日更新 |
| 通貨の重複 | 既定は制限なし。`max_ccy_positions` で同じ通貨を同じ向きに持つ本数を制限できる（約定時刻順に判定） |
| 損益 | USD。クォート通貨のUSD換算は1分足の仲値。R＝損益÷200ドル |
| コスト | スプレッド＝平均相対スプレッドを往復1回分。スワップ＝`swap_data/fx_swap.csv`（1万通貨あたりの円、単位は未確認）を `swap_costs.apply_interest` で反映。`PnL_Gross`（スワップ前）・`Interest` を取引履歴に残す |
| 期間 | 2021-01-01〜2025-12-31（2020年は200日線・52週用の助走）。期間末に持ち越したトレードは最終価格で計上 |
