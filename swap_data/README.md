# 金利調整額データ

`gold_spot_interest.csv` は GMO クリック証券「金利調整額」シート（Googleスプレッドシート `GMO_CFD_調整額` の「金利調整額」タブ）の金スポット分。

- 列: `date`（発生日）, `sell`（売り）, `buy`（買い）, `days`（付与日数）。単位は 1オンスあたりの円
- 付与日数が 0 の日（土日・休場日）は省いてある（調整額なし）
- 収録期間: 2020-01-02 ~ 2025-12-31（1,470行）。`buy = -sell - 2 × days` が全行で成り立つ
- 2026年以降を検証するときは、シートから同じ形式で行を追加する（日付順でなくてもよい）
- 計算ルールは `swap_costs.py` の冒頭を参照
