日足ダウ押し目ブレイク 6ペア

日足で高値・安値を切り上げて押し目が確定したら直近高値の上抜けで買い（売りは逆）、損切りは押し目の安値 / 2021-01〜2025-12（SP500 は 2024〜）/ 条件決め 2021〜2023・確認 2024〜2025 / 1回の損失 1%

条件決め期間で選んだ設定: 左右3本・ATR×1.0 / 利確 2R

合格ラインに届いた設定はなし。
12通りすべてで優位性は見えなかった

合格ライン（事前に決めたもの）: 全期間 PF ≥ 1.2、前半・後半ともプラス、6ペア中4ペア以上でプラス。選んだ設定は前半 +4.7R → 後半 -4.4R。

わかったこと

優位性なし押し目ブレイクの当たる確率がほぼ偶然と同じ

2R 利確の勝率は 34%。2R 利確で収支トントンになる勝率は 33% なので、「押し目の安値に先に戻るか、2R 先に届くか」はほぼ五分五分の確率どおり。日足の形だけでは方向の手がかりになっていない。

逆効果押し目への追従は利益を早く切る

新しい押し目に損切りを上げる決済は PF 0.5〜0.96 と最も悪い。左右2本の押し目は浅く、平均の勝ちが 0.9R しかない。損切りが動く前に −1R で終わる取引が全体の約3分の1あり、それだけで −26〜−33R。

想定外取引数がかなり少ない

6ペア × 5年で 64〜106 回（1ペア年2〜4回）。事前の見込み（150〜300回）の半分以下で、結果の差の多くは偶然の範囲。「押し目が確定してから高値を抜く」までに日足で数日かかり、その間に形が崩れることが多い。

補足最小スイング幅はほぼ効かない

ATR × 0.5 と 1.0 の結果はほぼ同じ。日足の左右2〜3本のスイングは、もともと ATR 1本分以上の幅があることが多い。

売買ルール・設定

日足とスイング

NY 17時区切りの日足。左右 2 または 3 本より厳密に高い（低い）日をスイングとし、ATR(14) × 0.5 / 1.0 未満の揺れは採用しない。高値と安値は交互に並ぶ（dow_trend.py と同じ）。

買いの条件

確定したスイングが 前の高値 → 前の安値 → 直近の高値 → 押し目の安値 の順で、高値・安値とも切り上げ、どちらもまだ抜かれておらず、直近の高値と押し目の差が日足 ATR の 0.5〜3.0 倍。売りはすべて逆。

注文

前日の終値で条件を判定し、翌日に直近の高値へ買い逆指値。その日のうちに押し目の安値に触れたら取り消し、1日1回まで。ポジションは1ペア1つ。約定は1分足で判定。

決済・枚数

損切り = 押し目の安値。決済は3通り: 新しい押し目が確定するたびに損切りを引き上げる / 利確 2R / 利確 3R。1回の損失 = 資金の 1%。スプレッド込み。

読むときの注意

  • エンジンは新しく書いたもの。同じルールを backtesting.py でも書き、6ペア × 2設定 × 3決済の 36 通りで取引履歴と損益が完全に一致することを確認した。
  • 取引数が少ないため、1つの設定の良し悪しを数Rの差で判断できない。ここで言えるのは「はっきりした優位性は無い」まで。
  • 以前の4時間足の検証（1回2%リスク）とは足の長さ・損切りの決め方・取引数が違うので、合計Rを直接比べられない。平均R（1回あたり）で見ると、今回は −0.26〜+0.01R、4時間足のダウ構造ブレイクは +0.03〜+0.06R。
  • SP500 は 2024 年からのデータだけ。
